## Descripción del sitio

El sitio web de promoción tuírsita para la comuna ficiticia "Destino Cordillera" tiene como objetivo mostrar los atractivos turísticos de la zona, incluyendo algunas actividades que se pueden realizar a aire libre dentro de la comuna, junto a lugares de interés para visitar y conocer, además, de qué posee un apartado dedicado al alojamiento y a la gastronomía local de la zona, finalizando con un apartado de contacto para que aquellos interesados puedan comunicarse para obtener más información respecto a los atractivos a visitar y actividades a realizar dentro de la comuna.
