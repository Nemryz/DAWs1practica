## Descripción del sitio

El sitio web de promoción turística para la comuna ficticia "Destino Cordillera" tiene como objetivo mostrar los atractivos turísticos de la zona, incluyendo algunas actividades que se pueden realizar a aire libre dentro de la comuna, junto a lugares de interés para visitar y conocer, además, de qué posee un apartado dedicado al alojamiento y a la gastronomía local de la zona, finalizando con un apartado de contacto para que aquellos interesados puedan comunicarse para obtener más información respecto a los atractivos a visitar y actividades a realizar dentro de la comuna.

## Instrucciones para ejecutar o visualizar el sitio

El sitio web es estático, no requiriendo de antemano de un servidor web para su visualización, por lo que puede ser ejecutado directamente desde el navegador web de su preferencia, abriendo el archivo 'index.html' que se encuentra en la raíz del proyecto.

1. Clonar el repositorio en su máquina local usando el siguiente comando:

   ```bash
   git clone https://github.com/Nemryz/DAWs1practica
   ```

2. Abrir el archivo 'index.html' mediante VS Code o la herramienta de su preferencia que permita abrir archivos HTML, o bien, abrirlo directamente desde el navegador web sea Chrome, Edge, Firefox o cualquier otro navegador compatible.

    Para navegar por el sitio web, puede hacer clic en los enlaces de navegación que se encuentran en la parte superior de la página, o bien, puede abrir directamente los archivos 'pagina1.html', 'pagina2.html' y 'pagina3.html' que se encuentran en la raíz del proyecto.

    De este modo, podrá visualizar el contenido de cada una de las páginas del sitio web.

    Mediante F12 o Ctrl+Shift+I (Cmd+Option+I en Mac) puede abrir las herramientas de desarrollo del navegador para inspeccionar el código fuente y los estilos aplicados a cada elemento de la página web. El código fuente de cada página web no se encuentra ofuscado, por lo que puede ser visualizado y analizado libremente.
